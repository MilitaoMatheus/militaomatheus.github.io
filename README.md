## 🧭 O Que Você Encontra no Portfólio

O website foi estruturado e desenvolvido seguindo um briefing de design de alto padrão (estética moderna, minimalista, dark mode nativo, espaço negativo generoso e zero excesso de elementos), funcionando tanto como **apresentação profissional** quanto como **cartão de visita digital interativo**.

## 💻 Arquitetura Técnica & Decisões de Engenharia

O projeto foi intencionalmente construído com **Zero Dependências Pesadas** (sem frameworks complexos ou bibliotecas externas volumosas), priorizando desempenho máximo, acessibilidade e carregamento instantâneo:

- **HTML5 Semântico**: Estruturação baseada em boas práticas de acessibilidade (WCAG), tags de navegação, cabeçalhos hierárquicos e metatags para SEO e Open Graph.
- **CSS3 Moderno**: Utilização de Custom Properties (CSS Variables) para gerenciamento completo dos temas Dark/Light, layout baseado em CSS Grid e Flexbox, tipografia fluida com `clamp()` e animações suaves aceleradas por hardware.
- **JavaScript Vanilla Modular (ES6+)**:
  - Controlador de tema com script anti-FOUC no `<head>`.
  - Mecanismo de Scroll Spy e detecção de rolagem para a navbar.
  - Filtro em tempo real de projetos com transições de visibilidade.
  - Gerenciador da área de transferência (`navigator.clipboard`) com fallback robusto.
  - Validação e redirecionamento de formulário de contato.
- **Canvas de Fundo (`particles.js`)**: Rede cibernética interativa de partículas em nós dourados que responde ao cursor do mouse e adapta contraste e densidade dinamicamente com base no tema ativo e nas preferências do sistema (`prefers-reduced-motion`).

## 🛠️ Como Executar Localmente

Como o projeto é estático e puro, não requer instalação de pacotes (`npm` ou gerenciadores pesados):

### Método 1: Servidor Local Simples via Python
Na raiz da pasta do projeto, execute no terminal:
```bash
python -m http.server 8000
```
Em seguida, abra no navegador: `http://localhost:8000`

### Método 2: Extensão Live Server (VS Code)
Abra a pasta no **VS Code**, clique com o botão direito em `index.html` e selecione **"Open with Live Server"**.
